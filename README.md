III. Course Orientation
Course description: IPT101 guides students from foundational programming to independent mastery using JavaScript, Git, Node.js, Express, and MongoDB. The course emphasizes server-side scripting, asynchronous programming, RESTful API design, database management, debugging, documentation, and deployment.
Course Learning Outcomes (approved syllabus wording)
      CLO 1: Understand and recognize core JavaScript ES6 syntax, Git version control commands, and the Node.js runtime architecture.
      CLO 2: Apply built-in Node.js modules, file systems, and asynchronous programming techniques to construct basic server-side scripts.
      CLO 3: Analyze, debug, and solve integration challenges by building robust RESTful APIs using Express.js and testing them via Postman.
      CLO 4: Integrate MongoDB databases, user authentication (JWT), and comprehensive error handling into web applications.
      CLO 5: Independently design, develop, deploy, and defend a fully functional integrative web system adhering to industry best practices.
